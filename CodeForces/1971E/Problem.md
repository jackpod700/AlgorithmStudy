
# E. Find the Car

## 문제 설명

Timur는 자동차를 타고 수직선 위의 위치 `0`에서 위치 `n`까지 이동하고 있습니다. 자동차는 0분에 위치 `0`에서 출발합니다.

수직선에는 총 `k+1`개의 표지판이 있으며, 각각 위치 `0, a₁, a₂, ..., aₖ`에 있습니다.

Timur는 자동차가 각 표지판에 도착하는 시간이 각각 `0, b₁, b₂, ..., bₖ`분이라는 것을 알고 있습니다.

수열 `a`와 `b`는 모두 뒤에 오는 값이 반드시 앞의 값보다 크며, `aₖ = n`입니다.

![사진](https://espresso.codeforces.com/c5ec45581a60511ef12703d09478d2b514395067.png)

자동차는 **인접한 두 표지판 사이에서 일정한 속도로 이동**합니다.

Timur는 총 `q`개의 질문을 합니다. 각 질문에서는 정수 `d`가 주어집니다.

여러분은 자동차가 위치 `d`에 도달하기까지 걸리는 시간을 분 단위로 계산하고, **소수점 이하를 버린 정수 값**을 출력해야 합니다.

## 입력

첫 번째 줄에는 테스트 케이스의 개수 `t`가 주어집니다.

- `1 ≤ t ≤ 10⁴`

각 테스트 케이스는 다음과 같이 구성됩니다.

**첫 번째 줄**

세 정수 `n`, `k`, `q`가 주어집니다.

- `k ≤ n ≤ 10⁹`
- `1 ≤ k, q ≤ 10⁵`
- `n`: 자동차의 최종 목적지
- `k`: 도착 시간을 알고 있는 표지판의 개수 (출발점 제외)
- `q`: 질문의 개수

**두 번째 줄**

`k`개의 정수 `a₁, a₂, ..., aₖ`가 주어집니다.

- `1 ≤ aᵢ ≤ n`
- `aᵢ < aᵢ₊₁` (1 ≤ i < k)
- `aₖ = n`

각 표지판의 위치를 나타냅니다.

**세 번째 줄**

`k`개의 정수 `b₁, b₂, ..., bₖ`가 주어집니다.

- `1 ≤ bᵢ ≤ 10⁹`
- `bᵢ < bᵢ₊₁` (1 ≤ i < k)

자동차가 각 표지판에 도착하는 시간을 나타냅니다.

**이후 q개의 줄**

각 줄에 하나의 정수 `d`가 주어집니다.

- `0 ≤ d ≤ n`

자동차가 위치 `d`에 도착할 때까지 걸리는 시간을 구해야 합니다.

**추가 제한**

- 모든 테스트 케이스에서 `k`의 합은 `10⁵`을 초과하지 않습니다.
- 모든 테스트 케이스에서 `q`의 합은 `10⁵`을 초과하지 않습니다.

## 출력

각 질문에 대해 자동차가 위치 `d`에 도달하기까지 걸리는 시간을 **소수점 이하를 버린 정수**로 출력합니다.

각 테스트 케이스의 답은 한 줄에 공백으로 구분하여 출력합니다.

## 예제 설명

### 첫 번째 테스트 케이스

자동차는 위치 `0`에서 위치 `10`까지 10분 동안 이동합니다.

따라서 이동 속도는 분당 1입니다.

- 위치 `0`: 0분
- 위치 `6`: 6분
- 위치 `7`: 7분

### 두 번째 테스트 케이스

자동차의 이동 속도는 구간마다 다릅니다.

- 위치 `0` ~ `4`: 분당 1
- 위치 `4` ~ `10`: 분당 2

따라서 각 질문의 결과는 다음과 같습니다.

- 위치 `6`: 5분
- 위치 `4`: 4분
- 위치 `2`: 2분
- 위치 `7`: 5.5분 → 소수점 이하를 버려 5분

### 네 번째 테스트 케이스

자동차의 이동 속도는 분당 1.2입니다.

- 위치 `2`: 약 1.66분 → 1분
- 위치 `6`: 5분
- 위치 `5`: 약 4.16분 → 4분
